# Afterlight 本地验收

日期：2026-10-16。开发分支：`feature/afterlight-theme`。最初验收只在本地进行；随后用户确认正式采用主题，并授权本地合并、验证后推送。正式配置现已选择 Afterlight；下文记录本地验收证据及其边界。

结论：当前版本的主要阅读与交互功能通过本地验收。已确认的问题见下表，修复后复查通过；这不等同于真实设备和线上服务均已验收。

## 本轮发现与修复

| 问题 | 修复结果 |
| --- | --- |
| 数学 CDN 响应慢会阻塞后续脚本，搜索、配色和阅读工具一起等待 | 数学引擎独立异步加载；本地控件先可用；较慢时显示加载说明，失败时给出刷新重试提示 |
| 关于页的原始 HTML 标题没有 ID，目录看得见但无法跳转 | 主题仅在生成的阅读内容中补充唯一标题锚点；原文件及已有 ID 保留；同名标题和 ID 冲突已验证 |
| 旧文章的 `not-gallery-item` 排除标记未被继承 | 图库识别原有排除标记，关于页的助手展示图不再被当成文章照片 |
| 320px 归档页说明挤压标题，断行不自然 | 窄屏将说明置于标题下方，并平衡标题断行 |
| 浅色模式下深色精选卡片的悬停文字变成暗棕色 | 卡片使用适合深色背景的强调色；悬停文字对比度提高 |
| 关于页部分小字、音乐说明和 Co/End 引言沿用固定颜色；深色下部分文字偏暗 | 在主题侧接入配色变量，并让关于页标签底色服从手动主题选择 |
| 深色模式打印时仍保留浅色文字变量 | 打印时恢复浅底深字的主题变量，解除弹层对正文滚动的限制 |
| 部分数学文章及关于页的页面描述为空 | 提供标题和站点介绍组成的描述回退，避免将公式源码当作摘要 |

## 检查范围与结果

- Afterlight：17 篇文章、103 个路由、58 个 HTML 页面；Icarus：17 篇文章、109 个路由。两套主题均构建成功。
- 全部 17 篇文章的正文、原有锚点、图片和 AI 使用说明与本轮 Icarus 输出一致。关于页新增锚点只影响主题生成结果。
- 58 个 HTML 页面的本地资源链接及站内片段目标检查通过，无断链和断裂锚点。
- 17 篇文章加首页、归档、首页第二页、关于页，共 21 页 × 1440/320px，42 个布局状态：未发现整页横向溢出、MathJax 错误、页面脚本异常或失败资源响应。
- 长期回归另覆盖 10 页 × 1440/768/390/320px：搜索和失败重试、配色、目录、专注模式、拖动和触摸、会话保持、图库、音频实际播放、禁用存储和无 JavaScript 正文。
- 新增长期回归：关于页目录目标存在并可跳转，图库继承旧排除标记；人为挂起与中断数学引擎请求时，搜索、配色和专注阅读仍可用，加载及失败提示正常。
- 白猫四段正文与五张图片、图库真实触摸横滑、图片失败后恢复、搜索特殊字符、横屏弹层边界、减少动态效果检查通过。
- 已查看首页、归档、关于页、数学、音乐及深浅色手机截图，并检查横屏目录末尾可达、打印配色变量和标题锚点碰撞处理。

长期回归：`npm run check:afterlight`，需要本地预览服务、最新的两套主题构建以及 Playwright 环境。临时扫描与截图位于忽略目录 `.afterlight-preview/`：`audit-scan.cjs`、`audit-scan.json`、`audit-fixes.cjs`、`audit-*.png`。本轮补充的关键功能检查已纳入长期回归文件。

## 剩余事项

- 首页图片体积问题已在同日后续优化：主照片和白猫精选图使用多尺寸 WebP／JPEG，原图保留。两图从合计约 11.6 MiB 降至本地实测约 145–288 KiB（常见桌面和手机状态）；画框、显示尺寸和裁切位置保持一致。线上弱网的实际耗时尚未验收。生成与维护说明见主题 README。
- 字体依赖本地字体栈，其他设备的字体与换行可能不同，尚未对跨设备一致性作出保证。
- 本次使用本机 Chrome 自动化和触摸／视口模拟；实体手机、软键盘、Safari、Firefox 尚未实际验收。
- 本地预览评论保持禁用。正式发布时已检查发布域名上的真实 Giscus 评论框，修复将正常空讨论误判为加载失败的问题；离线回归覆盖空讨论、无关消息、错误反馈与重试（`node tools/afterlight-comments-check.cjs`，使用相同 Playwright 环境）。未执行登录、提交评论或反应。
- 用户对关于页、首页引言和底部短句的修改均保持原样，并随正式采用主题的提交一起纳入发布版本。
