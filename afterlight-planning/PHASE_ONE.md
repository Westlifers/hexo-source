# Afterlight 第一阶段预览

本阶段完成使用真实内容的首页与文章页，可在本地浏览并讨论视觉方向。开发位于 `feature/afterlight-theme`，正式配置仍使用 Icarus；未推送或部署。

## 查看页面

运行 `npm run preview:afterlight`，打开 http://127.0.0.1:4173/ 。已经运行时直接打开页面即可。

- 首页使用原版「Yougi 杨荻」签名、关于页的山间照片、《做一首世俗的诗》的标题与原句。
- 精选区同时展示白猫随笔的有图版式和 Route Six 的无封面文字版式。
- 最近文章由 Hexo 分页数据生成，17 篇文章分两页展示，精选不改变分页数量。
- 文章页包括正文、分类标签、日期、基础目录、专注阅读和上下篇导航。
- 归档、分类、标签和关于页提供基础模板，使预览中的导航完整可用。
- 配色支持系统、浅色、深色三种状态，并保存选择。

优先查看：普通随笔《做一首世俗的诗》、定制随笔《日光之下，有一只白猫》、诗歌 Route Six 和数学文章 Integral quantaloid 的 weak tabularity 与 topos。

## 实现取舍

使用仓库已安装的 EJS 渲染器，无新增依赖。新主题位于 `themes/afterlight/`；预览配置、缓存、输出及自动检查材料均放在已忽略的 `.afterlight-preview/` 中。旧 `public/` 与站点数据库不参与本次构建。

原阅读脚本仅在 Afterlight 下停止注入，新主题暂用基础目录和专注模式。数学内容生成、证明折叠与引用增强、AI 说明仍沿用现有站点扩展；当前不是完整的脚本迁移。

所有文章、媒体及其 front-matter 保持原样。白猫文章在小屏上的原有浮动优先级问题由主题侧适配；定理块和白猫文字增加了深色兼容。初版以浅底承托旧签名，现已由下述第一轮调整中的新矢量签名替换。
