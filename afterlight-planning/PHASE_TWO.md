# 第二阶段：内容与阅读能力

当前阶段保留已经确认的视觉方向，仍在 `feature/afterlight-theme` 本地开发。没有改动文章、媒体、正式主题选择、远程仓库或部署流程。

## 接入结果

| 能力 | 新主题实现 | 原实现的去向 |
| --- | --- | --- |
| 阅读工具 | `reading.js` 与主题模板：专注、目录、章节高亮、回顶、拖动、会话记忆、键盘移动／重置 | Icarus 的阅读脚本及样式保留，只在 Afterlight 下禁用注入 |
| 搜索 | 主题生成本站 JSON 索引，按需搜索标题、正文、标签、分类；支持页面、失败重试、空结果和快捷键 | Afterlight 无 Insight／PJAX 依赖，旧主题继续使用原方案 |
| 数学生成 | 原 Pandoc／Lua 渲染器、编号和语义 HTML 保留 | 不改变作者写作语法与逐篇启用方式 |
| 数学阅读 | 主题内的证明折叠、命题／证明互链、目标展开、公式和交换图局部滚动；统一 MathJax 初始化 | 原数学前端 JS／CSS 不再注入 Afterlight，保留供 Icarus 使用 |
| AI 说明 | 共用原等级和默认文案，由 Afterlight 标题信息区渲染；保留自定义说明链接 | 旧主题仍在正文注入，不重复声明 |
| 图片浏览 | 点击／键盘打开、前后张、原图链接、Escape 关闭及焦点恢复 | 不接管指向其他页面的图片链接，不处理公式或交换图 |
| 评论 | Giscus 组件、原仓库与分类、原 pathname 映射、按需加载、主题同步与失败重试 | 本地构建与本机地址双重禁用，线上联调留待发布前 |

归档、分类、标签、分页、关于页和上下篇沿用第一阶段实现。本阶段没有引入 PJAX，也没有修改诗歌、白猫随笔或音频文章的正文。导航新增搜索图标；浮动工具仅在阅读页面出现。

## 检查与证据

- Afterlight 构建成功：17 篇文章、102 个路由；搜索索引含 17 篇文章和关于页，不含数学验收草稿。
- Icarus 独立构建成功：17 篇文章、109 个路由。逐篇核对两主题正文文字、正文锚点、图片地址和 AI 声明内容一致；唯一预期位置差别是 AI 声明移到标题信息区。
- 扫描全部生成 HTML 的本地链接，无缺失目标；Afterlight HTML 不再引用旧阅读／数学／AI 前端资源，没有重复初始化。
- 搜索检查：标题／标签／正文可查、无结果提示、索引加载失败后重试、Ctrl＋K、Escape、关闭后焦点恢复。
- 阅读检查：专注跨文章和刷新保持，首页不进入专注；拖动位置保持，Alt＋方向键移动、Home 重置；目录弹层关闭不退出专注；触摸拖动后可再次点开并跳转目录。
- 数学检查：marked 与 Pandoc 真实文章公式可渲染，无 MathJax 错误节点；每页只有一份 MathJax 加载，证明关联存在，跳转会展开折叠目标。
- 图库检查：白猫文章五张实图、键盘打开、前后切换、关闭后焦点恢复及深色显示。
- 响应式：首页、归档、第二页、关于、随笔、白猫、两种数学文章、音频和诗歌共 10 页，各测 320／390／768／1440px，40 个状态无整页横向溢出。
- 音频实际静音播放并确认时间推进。无 JavaScript 时正文及 AI 声明可读；禁用浏览器存储后专注功能仍可使用。
- 本地 `/simple/` 子路径抽测搜索索引、结果链接、数学资源和目录跳转成功。
- Giscus 使用网络完全拦截的模拟客户端验证属性、失败重试、单一 iframe 与浅深色消息；没有连接真实评论服务，没有读取或写入线上讨论。

检查中修复了搜索输入框优先吞掉 Escape、鼠标快速移出图标导致拖动中断，以及移动浏览器拖动后省略下一次兼容 click 的问题。相关行为已加入可重复运行的浏览器检查。

主要检查入口：`tools/afterlight-check.cjs`。本地结果及截图位于 `.afterlight-preview/phase-two-checks.json`、`phase-two-search.png`、`phase-two-gallery-dark.png`、`phase-two-directory-mobile.png`、`phase-two-tools-mobile.png`；评论模拟检查材料也保存在该忽略目录。

## 后续边界

线上 Giscus 的真实讨论读取、登录与发送尚未验证，本地评论区明确标示未加载。发布前需要核对部署域名和讨论匹配，但本阶段不进行任何远程写入。

数学仍依赖 MathJax 与 TikZ 字体 CDN；原始图片尚未压缩，字体仍使用系统字体栈。目标 CI、完整发布元信息、实体手机和所有定制作品的视觉细节留到第三／四阶段。本地无头 Chrome 的通过不等于线上或全部浏览器验收。
